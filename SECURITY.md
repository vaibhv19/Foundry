# Security Policy

## Supported Versions

Only the current main version of Foundry is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:       |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it immediately by opening a private security advisory report under the GitHub repository's **Security** tab, or by contacting the maintainer directly.

Please do not open public issues for security disclosures to allow for responsible disclosure and mitigation.
